# Template de etapa — uso externo substituido

O antigo template de prompts externos foi substituido pelo
[protocolo Codex CLI](../WORKFLOW_CODEX_CLI.md). Este arquivo permanece para
compatibilidade de referencias; nao deve ser preenchido para iniciar etapas.

Na sessao do Codex CLI, use `continue o projeto`, `mostrar status` ou
`validar etapa atual`, conforme o protocolo. O plano curto e as evidencias sao
apresentados na propria sessao, com escopo e aceite lidos diretamente do
[backlog canonico](../Projeto%20Stroop%20Test.md), sem copiar o backlog para prompts.
