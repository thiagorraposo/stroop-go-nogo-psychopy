# Copy das telas

Textos sugeridos para a proxima versao visual do experimento. Estes textos estao prontos para copia futura em componentes do PsychoPy, mas ainda nao foram implementados.

## Tela 01 - Abertura

Titulo:

Tarefa de Correspondencia de Cores

Corpo:

Nesta tarefa, voce vera palavras de cores escritas em cores diferentes.

Pressione Espaco apenas quando a palavra e a cor das letras forem iguais.

Quando forem diferentes, aguarde a proxima tentativa.

Botao primario:

Iniciar tutorial

Alternativa de teclado:

Pressione Espaco ou Enter para continuar.

## Tela 02 - Introducao a pratica

Titulo:

Pratica

Corpo:

Voce fara algumas tentativas de treino.

Pressione Espaco apenas quando a palavra e a cor forem iguais.

Durante a pratica, voce recebera feedback apos cada tentativa.

Botao primario:

Comecar pratica

Alternativa de teclado:

Pressione Espaco ou Enter para comecar.
