# Assets

Esta pasta armazena apenas assets proprios do projeto, como imagens, icones ou elementos visuais criados para o experimento.

Nao incluir logotipos, imagens, textos visuais ou elementos proprietarios de terceiros. Imagens usadas apenas como referencia nao devem ser redistribuidas como parte deste repositorio.

`assets/ui/` fica reservado para futuros elementos de interface proprios.
